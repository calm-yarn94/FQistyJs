# 项目简介

## 核心功能
- 基于YOLOv8的俯视行人车辆检测系统，支持6类目标检测（bus、car、bicycle、person、truck、motorcycle）
- 包含7000张标注数据集及训练好的模型
- 支持多种输入源：单张图片、图片文件夹、视频文件、本地摄像头
- 提供实时显示功能：目标位置、目标总数、置信度等信息
- 支持参数调整：自定义置信度、IOU阈值
- 提供界面选项：选择显示标签和原图
- 支持模型选择和批量检测
- 包含完整运行教程和UI界面源文件

## 适用场景
- 俯视角下的交通监控与车辆行人计数
- 智能停车场管理系统
- 校园或社区安防监控
- 交通流量分析研究
- 行为分析与统计应用

## 技术特点
- 采用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 基于Python3.9，依赖opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 提供完整源码、数据集、训练结果和运行教程
- 配置成功环境可直接使用，无需额外训练
